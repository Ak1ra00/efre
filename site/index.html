Offline password vault for Windows

The vault that opens only with your YubiKey.

efre keeps your passwords, notes and cards in one encrypted file on your PC. There is no master password, no account and no cloud. Plug in your key, enter its PIN and touch it to get in.

Opening the vault

No master password to guess, phish or forget.

The secret that opens efre lives inside your YubiKey and never leaves it. Windows asks for the key's PIN, you touch the key, and the vault opens.

  1. Plug in your YubiKey

    Either of your enrolled keys works.

  2. Enter its PIN

    Or use your fingerprint on a YubiKey Bio. After 8 wrong PINs, the key locks itself.

  3. Touch the key

    The key hands efre its hmac-secret, which unwraps your vault key. Nothing else can.

Inside

Everything a vault needs. Nothing that phones home.

  • Every kind of secret

    Logins, secure notes in Markdown, cards, identities, and custom items with any fields you need.

  • Find anything

    Fuzzy search ignores typos and accents, so nwb finds Northwind Bank. Tags, favorites and three sort orders.

  • Reveal and copy safely

    A hidden field shows for 10 seconds. Copies skip clipboard history and cloud sync, and clear after 30 seconds.

  • Undo mistakes

    Deleted items go to the trash, with an undo right away and a restore any time later.

Generator

Strong passwords and passphrases

Generate passwords of up to 128 characters, or passphrases from the EFF long word list. The meter shows the strength in bits of entropy, and the value is made in efre's core with your PC's secure random number generator.

Your keys

Two keys, one vault

Enroll a primary key and a backup. If you lose one, remove it with the other: efre makes a new vault key and re-encrypts everything, so the lost key opens nothing new.

  • Adding, renaming or removing a key needs a fresh PIN and touch
  • efre reminds you while only one key is enrolled
  • It won't let you remove your last key

How it works

Your key unlocks a key, which unlocks the vault.

efre never stores anything that can open the vault on its own. Each YubiKey wraps the same random vault key under a key of its own, made from a secret the YubiKey gives only after its PIN and a touch.

  1. Your YubiKey answers

    After the PIN and a touch, it returns a secret through Windows' WebAuthn API.

  2. efre derives a key

    HKDF-SHA256 turns that secret into a key-encryption key for this YubiKey only.

  3. The vault key unwraps

    That key unwraps the random 256-bit vault key, and HMAC-SHA256 checks the header and the item list.

  4. Items decrypt in the core

    XChaCha20-Poly1305 decrypts items inside efre's Rust core. The window sees a password only when you reveal it.

  • FIDO2 hmac-secret
  • credProtect level 3
  • HKDF-SHA256
  • XChaCha20-Poly1305
  • HMAC-SHA256
  • 256-byte padding
  • SQLite · WAL · secure_delete
  • WebAuthn API 4+

0network connections

Offline by design

Nothing leaves your PC.

efre has no network code at all: no account, no sync, no telemetry and no update checks. Every build is started on Windows by the project's CI, which fails if efre or its window opens a single socket, even to the PC itself.

Security

What efre protects, and where it stops.

A vault should be honest about its limits. efre lists them in its own settings, too.

It protects you from

  • Someone who copies your vault file. Without an enrolled key and its PIN, they can't decrypt anything.
  • Tampering. Changing, deleting or swapping any part of the file is detected, and efre refuses to open it.
  • A stolen YubiKey. It still needs its PIN, which locks after 8 wrong tries. Remove it, and it opens nothing new.
  • Phishing sites. efre's credential uses the ID efre:, which no website can ask for.
  • Screenshots. efre's window is hidden from screenshots and screen recording.

It can't protect you from

  • Malware running while the vault is open. It can read the screen and efre's memory, as it could any app's.
  • An older copy of the whole file. Restoring a complete older vault file can't be detected.
  • Losing every key. There is no recovery code. Enroll a backup key.
  • Cameras and some remote-desktop tools. Screenshot blocking doesn't stop them.

The name

Named for a cave.

efre comes from Tamazight, the language of the Amazigh people of North Africa. A cave keeps what matters out of sight, and only those who know the way in can reach it. That's the idea behind efre: your secrets stay in one place on your own PC, and only your key opens it.

Install

Ready in a few minutes.

  1. Download the installer

    From the latest release on GitHub. It's one file with everything efre needs.

  2. Check it

    Optional, but worth a few seconds: compare its SHA-256 with the one on the release page.

    (Get-FileHash .\efre_0.1.1_x64-setup.exe -Algorithm SHA256).Hash

  3. Run it

    SmartScreen warns because the installer isn't code-signed yet: choose More info, then Run anyway. There's no admin prompt, and nothing is downloaded.

  4. Enroll your keys

    The setup wizard walks you through your primary key and your backup key. Each one asks for its PIN and a touch, twice.

You'll need

  • Windows 11 with current updates. efre needs Windows' WebAuthn API version 4 or later.
  • Two YubiKeys with FIDO2: the YubiKey 5, Security Key or Bio series.
  • A FIDO2 PIN on each key. Set it in Windows Settings › Accounts › Sign-in options › Security key.
  • WebView2 draws efre's window. It's built into Windows 11, and the installer adds it if it's missing.

Questions

Before you start

What happens if I lose both keys?

Then nobody can open the vault, including you. There is no recovery code, on purpose. Keep your backup key somewhere safe, away from your PC.

Can I sync it between computers?

No. efre is offline by design. The vault is a single file, %LOCALAPPDATA%\efre\vault.efre, which you can back up or copy yourself. It opens on any PC with efre installed when one of its keys is plugged in.

Does it work on Windows 10?

Only if Windows reports WebAuthn API version 4 or later, which depends on its updates. efre checks when it starts and tells you if Windows is too old.

Which security keys work?

YubiKeys with FIDO2: the YubiKey 5 series, the Security Key series and the YubiKey Bio. efre checks a key's attestation when you enroll it.

Why is the installer 211 MB?

It carries Microsoft's offline WebView2 installer, so nothing is downloaded during setup. That part runs only if your PC doesn't have WebView2 yet.

Is efre free?

Yes. It's open source under the MIT License, with no account, no subscription and no ads.
